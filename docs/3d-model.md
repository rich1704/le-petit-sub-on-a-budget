# 3D model

The sub between a pair of Le Petit, to scale: the same 340 × 530 front, the same 22 mm OSB, the
drivers firing sideways from the sides. Drag to turn, scroll or pinch to zoom, hover any part for its
size. **See-through**, the two **cuts** and **Exploded** show the inside; **Play bass** moves both cones
out together — the reason the box stands still.

| View | What you see |
| --- | --- |
| **Closed** | the finished box next to the pair: plain front, flush drivers in the sides |
| **See-through** | the OSB turns translucent: drivers, tie strip, window brace and wool in place |
| **Cut: front half off** | a section through the driver centres — the two magnets 38 mm either side of the tie strip |
| **Cut: right half off** | the section from the side: tie strip at driver height, window brace 330 below the top, wool below |
| **Exploded** | how the panels go together: plates over everything, sides between, top and bottom between those |

The model uses the same dimensions as the [building plan](building-plan.md); the drivers are drawn from
SB Acoustics' datasheet.
